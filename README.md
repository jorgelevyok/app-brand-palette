# Actividad 5 — Paleta de marca personalizada

Clase 7, Theming. La consigna pide practicar `react-native-paper` armando una paleta y aplicándola al tema de la app.

Esta pantalla no es un muestrario de colores. Es un resumen de plata: saldo, ingresos, gastos y presupuesto mensual, con los últimos movimientos. Los colores salen del tema de Paper (claro y oscuro), así que la interfaz cambia entera al tocar el ícono de sol o luna.

## Qué se puede hacer

- Ver el saldo disponible, los ingresos y los gastos.
- Ver cuánto del presupuesto mensual ya se usó.
- Revisar los últimos movimientos.
- Agregar un movimiento nuevo con el botón **+**: concepto, categoría, monto, y si es gasto o ingreso. El saldo, los totales y la barra se actualizan al guardar.
- Pasar de modo claro a modo oscuro.

## Cómo correrla

```bash
npm install
npx expo start
```

Después se puede abrir en Expo Go, en un emulador o en la web.
